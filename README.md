# 5HRV

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A scientific HRV calculator that analyses five-minute heart rate variability recordings using peer-reviewed physiological research and published age- and sex-specific reference populations.

https://5hrv.com

## Scientific foundation

5HRV interprets five-minute HRV measurements using the DanFunD reference population (Brinth et al., *Scand J Public Health*, 2022). Metrics include RMSSD (cardiac vagal modulation), SDNN (total short-term variability), and LF/HF (spectral distribution). All calculations are transparent, documented in the Methodology page, and open for inspection.

## Open Source

5HRV is released under the MIT License.

The source code, algorithms and implementation are freely available for inspection, research and reuse.

If you use 5HRV in research, please cite the project and the underlying scientific references:

- Brinth LS et al. Age- and sex-specific reference values of short-term heart rate variability. *Scand J Public Health*. DOI: 10.1177/14034948221124020
- Task Force of the ESC/NASPE. Heart rate variability: standards of measurement, physiological interpretation, and clinical use. *Circulation* 1996; 93(5): 1043–1065.
